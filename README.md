# SA Elite Home Inspection

Marketing website for SA Elite Home Inspection, built with React, Vite, and Tailwind CSS.

## Pages

- Home (`/`)
- About (`/about`)
- Services (`/services`)
- Prices (`/prices`)
- Contact (`/contact`)

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — build for production (outputs to `dist/`)
- `npm run preview` — preview the production build locally
- `npm run lint` — run oxlint

## Tech Stack

- [React](https://react.dev/) + [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/) for client-side routing
- [Tailwind CSS v4](https://tailwindcss.com/) via `@tailwindcss/vite`

## Notes

- The contact form (`src/pages/Contact.jsx`) currently simulates submission. Wire it up to a
  form backend (e.g. Formspree, Resend) before going live.
